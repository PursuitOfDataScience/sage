# Lower bounds are the part that matters. Generate a lockfile (`pip freeze >
# requirements.lock` or `uv lock`) for reproducible deploys.
#
# `anthropic` used to be listed here and was never imported. `pymupdf` was the
# reverse: imported as `fitz` but never declared, so the fast PDF path never ran.
#
# `mistralai` is the third case, and the reason `sage/providers/mistral.py` imports it
# inside the factory rather than at module scope: the ADAPTER stays — it is machinery,
# and a second deployment may declare a mistral provider — while the SDK it needs is
# a dependency only of a deployment that actually does. This one no longer does, so
# shipping it is megabytes of image for a code path nothing reaches.
# >=1.42 because `st.container(key=…)` — and with it the `.st-key-*` classes the
# whole stylesheet hooks onto — is not in 1.40/1.41. On those the app raises
# TypeError on import rather than merely rendering unstyled.
streamlit>=1.42,<2
# OpenCode Zen and any other OpenAI-compatible endpoint are called over plain
# HTTP. Declared explicitly because sage/providers.py
# imports it directly.
httpx>=0.27
pypdf>=4.0
pymupdf>=1.24
# Optional at runtime: without it images are sent at their original size, which
# for a 10 MB screenshot is ~13 MB on every turn it survives in the history.
pillow>=10.0
